# 🎮 Valorant Collage Generator

<img src="https://i.ibb.co/SDtrYLKB/image.png" alt="Valorant Bundle" width=120 align="right" />

A sleek web app that auto-generates **5 optimized collage images** from uploaded Valorant skin screenshots.  
Sorts skins by rarity tier (Exclusive → Ultra → Premium → Deluxe → Select → Unknown) and presents them in beautiful, shareable image grids — perfect for marketplaces that allow only 5 images.

---

## 🔗 Live Demo  
➡️ [Launch the Collage Generator](https://valorant-collage-app.streamlit.app/)  

---

## 🚀 Features
- 📤 Upload unlimited 1200x1200 Valorant skin images
- 🧠 Auto-sorts by tier: **Exclusive → Ultra → Premium → Deluxe → Select → Unknown**
- 🧩 Smart grid system (2x2 to 7x7) for best layout
- 🖼️ Displays **exactly 5 collage images**, no matter the input size
- 🎯 Centered per-image download buttons
- 📦 "Download All (ZIP)" feature
- 🌌 Fully responsive, modern **VALORANT-themed** UI
- ⚡️ Fast & efficient — powered by **Streamlit**

## 🧠 How It Works

> Skin filenames must start with their tier as prefix:
exclusive_reaver_vandal.jpg
premium_gaia_guardian.jpg
ultra_protocol_spectre.png
> Tier priority:
Exclusive → Ultra → Premium → Deluxe → Select → Unknown


> Collages:
- Dynamically chunked
- 5x fixed output (even for 100+ images!)
- Black background to match VALORANT aesthetic
